# Instalasi React Router

 Sekarang kita akan menjelaskan langkah-langkah memasang React Router pada proyek **React berbasis Vite**.

## Cara Instalasi di Project React Vite

Jalankan perintah berikut pada terminal di dalam direktori proyek Anda:

```bash
npm i react-router
```

Setelah proses instalasi selesai, kita sudah bisa langsung menggunakan fitur-fitur yang disediakan oleh **React Router**.

---

## 📝 Catatan Penting

* Perintah `npm i react-router` (singkatan dari `npm install react-router`) berarti kita meminta **NPM (Node Package Manager)** untuk mengunduh dan memasang paket (*package*) React Router ke dalam proyek kita.
* Pastikan Anda menjalankan perintah ini di dalam **folder proyek** yang tepat (bukan di luar folder proyek).
* Anda dapat memverifikasi keberhasilan instalasi dengan memeriksa file `package.json` pada bagian `"dependencies"`.
